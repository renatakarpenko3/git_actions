# Two Sum Program

The project implements a solution to the popular "Two Sum" problem from LeetCode. It includes a function that finds two numbers in a list that add up to a given target, along with automated tests using GitHub Actions.

# Problem Description

Given an array of integers `nums` and an integer `target`, return the indices of the two numbers such that they add up to the `target`.
# Example
Input: nums = [2, 7, 11, 15], target = 9  
Output: [0, 1]  
Explanation: nums[0] + nums[1] = 2 + 7 = 9
